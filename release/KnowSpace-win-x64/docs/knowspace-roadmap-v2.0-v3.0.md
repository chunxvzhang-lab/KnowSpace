### 1. 🎨 无限空间可视化白板 (Infinite Canvas · JSON Canvas 1.0 兼容)
*打破线性排版束缚，赋予知识第二维度的空间拓扑组织力。*
- **行业开放标准互通**：100% 遵循开放标准 **JSON Canvas 1.0**（`.canvas` 格式），与 Obsidian Canvas 等外部空间工具完全无缝双向互通。
- **多模态卡片挂载**：
  - **文本便签卡片 (Text Node)**：行内 Markdown 极速编辑，失焦自适应渲染（支持 LaTeX、代码高亮、Checklist）。
  - **文档内嵌卡片 (File Node)**：挂载库内任意笔记，卡片内实时滚动阅读，双击无缝穿梭直达原文档。
  - **分组容器 (Group Node)**：半透明分类容器，智能计算边界包围盒、支持自适应紧凑包裹（24px 留白）与一键解散容器。
  - **网页参考卡片 (Link Node)**：直观内嵌外部参考网站与标签。
- **严格几何中心对齐与垂直路由**：
  - 4 侧锚点严格定位在卡片边框正中点（`width/2`, `height/2`），连线与锚点圆点完全居中贴合。
  - 上下分层垂直优先路由算法：跨层级连线时起点严格在底部/顶部，彻底消除折返与无关卡片穿插。
- **智能拓扑色彩与环形识别系统**：
  - **发起源一致性**：同一卡片向外发出的所有连线自动使用同一种高亮色。
  - **容器内互斥分配**：同一分组容器内两张及以上卡片向外连线时，自动分配互斥的高对比度调色板颜色（历史文件即使存为相同颜色，打开时也会自动动态消除冲突）。
  - **环状闭环连线 (Ring/Cycle)**：自动检测环形闭环拓扑，闭环连线使用统一色彩；环内节点向外部发出的连线自动解耦，分配全新独立颜色。
  - **一对多发起源全景识别**：起点锚固圆点、卡片头部 `🌱 发起源 · N` 徽章、卡片外框发光源辉光。
- **连线形态与流向控制**：
  - 贝塞尔平滑曲线（抗冲天防大弧度约束）、正交折线（带交互式中点弯折拖拽手柄，双击秒级复位）、直线。
  - 实线、虚线、点线 3 种线型样式；单向箭头、双向箭头、无箭头，按 `R` 秒级反转流向。
  - Pill 胶囊、Rect 矩形、真·几何对称菱形 3 种关系说明徽章，自适应文本宽度与阴影。
- **批量操作与视口边界自适应**：
  - 框选/多选连线弹出底部浮动批量工具栏（一键批量改色、箭头、线型、虚实、反向与删除）。
  - 多选卡片右键菜单：一键打包为分组容器 (`Ctrl+G`)、**一键断开所选卡片间内部连线**（保留与外部连线）、批量水平/垂直对齐、水平/垂直等距分布。
  - 单卡片右键菜单：一键向右/向下一对多发散分支 (`Tab` / 多分支衍生)、提取为新笔记。
  - **右键菜单视口边界智能感知**：靠近屏幕底部或右侧时自动向上/向左翻转，彻底杜绝菜单溢出被状态栏遮挡。
- **全要素高保真图片导出与长文萃取**：
  - 缩略雷达小地图（Minimap）支持微缩卡片分布与快速视口平移。
  - **画布逆向拓扑萃取长文算法**：自动识别卡片空间坐标与有向因果依赖，一键逆向萃取为章节完备的 Markdown 专著。
  - **高保真图片导出（PNG / SVG / JPEG）**：支持 1×~4× 超高清导出，背景透明/暗色切换，画布渲染与导出文件完全 1:1 保持一致（连线颜色、环形弧度、箭头端点无任何色差与几何偏差）。

### 2. ✍️ 现代化极客编辑、双链与科学排版 (Editor & AST Engine)
*基于 CodeMirror 6 深度打造，毫秒级实时防抖渲染，极致键盘心流。*
- **全键盘斜杠命令补全 (`/`)**：在行首或空格后键入 `/` 呼出 20+ 项排版模板（各级标题、待办清单、GFM 智能表格、代码块、LaTeX 公式、Mermaid 架构图、Callout 提示框等），键盘直接选取填入。
- **Obsidian 级情境感知右键菜单**：
  - 选区一键提取创建独立 Markdown 新笔记（并在原文原地替换为 `[[双链]]`）。
  - 选区一键生成原子段落块引用（`^block-id`）。
  - 选区批量格式化（粗体、斜体、行内代码、`==高亮==`、删除线、各级列表转换）。
  - 实时统计浮层：选中字符数、词数、行数与预估阅读耗时。
- **原子互联系统**：
  - `[[WikiLink]]` 标题模糊匹配与双向补全。
  - `^block-id` 段落指纹标记、`[[doc#^block]]` 块引用跳转与 `![[doc#^block]]` 块级卡片内联嵌入。
- **AST 零延迟双向精准同步滚动**：富文本与源码高度差异无论多大均严丝合缝；正文段落点击微光联动源码定位。
- **专业排版与印刷导出**：
  - 打字机居中滚动模式 (`Alt + T`)。
  - LaTeX / KaTeX 科学公式行内与独立大块渲染。
  - Mermaid 架构图全要素渲染，支持以 3× Retina 超清导出 PNG。
  - Chromium 原生打印引擎与 `Ctrl+P` 高保真 A4 矢量 PDF 导出，配备跨页防截断保护。
- **三套专属调优主题**：日光浅色 (Daylight)、纸质墨水屏 (E-ink Paper)、极客暗黑 (Geek Dark)。

### 3. ⏳ 本地时间旅行与版本快照历史 (Local Version History · `Ctrl + Shift + H`)
*无感记录每一次知识创作的修改，纯本地运行、安全防丢的时光机。*
- **纯本地防丢安全架构**：在知识库根目录下维护 `.knowspace/snapshots/` 隐藏存储，绝不依赖云端。
- **30 秒去抖与 SHA-256 去重**：后台静默捕获实质变更，避免琐碎字符高频写入；单个文档自动维护最新 50 个优质快照点。
- **Myers LCS 细粒度对比视图**：
  - **Side-by-Side 双栏对比**：左右分栏高亮新增、修改与删除行，支持行内字符级微粒度高亮。
  - **Unified 单栏统览**：类似 Git Patch 的紧凑对比模式。
- **一键安全还原与里程碑快照**：可随时打入自定义命名里程碑标签，随时一键还原，并自动备份还原前的状态。

### 4. 🔍 全库毫秒级混合检索引擎 (Hybrid Vault Search · `Ctrl + F`)
*全新文档级与段落级高性能倒排索引，十万字知识库键入即出（< 15ms）。*
- **内存级倒排索引 (Inverted Index)**：建立 `tagIndex`、`linkIndex` 与 `termIndex`，告别单文档线性遍历。
- **结构化高级检索语法**：
  - 标签过滤：`tag:#架构` 或 `#架构`；
  - 双链引用：`link:[[分布式协议]]`；
  - 严格短语：`"Vector Database"`；
  - 排除筛选：`-草稿`；
  - 快捷语法辅助芯片（Filter Chips）：一键点击填入。
- **双模无缝切换**：当前章节过滤 vs 全库知识检索一键切换，命中匹配项伴有微光脉冲与精准行跳转。

### 🎯 Milestone 1：v2.1.0 · 空间智能与画布多模态进阶（2026 Q4 推进）
> **定位**：让白板从单纯的思维草稿板，跃升为支持富媒体、自由涂鸦与智能寻路的「超级多模态工作台」。

#### 1.1 画布多模态媒体卡片 (Rich Media Nodes)
- **图片卡片 (Image Node)**：
  - 支持从剪贴板截图或系统文件管理器直接拖拽 PNG/JPG/WebP/GIF/SVG 图片至画布生成独立卡片；
  - 支持等比拉伸、自由缩放、比例锁定与双击呼出毛玻璃全屏灯箱；
  - 导出 SVG/PNG 时自动内嵌 Base64 编码，确保导出离线文件独立可看。
- **音视频与 PDF 嵌入卡片 (Audio / Video / PDF Embed Nodes)**：
  - 支持将本地 MP3/WAV/MP4/WebM/PDF 拖入白板；
  - 音视频卡片内嵌轻量无边框播放条；PDF 卡片支持缩放与行内翻页预览。
- **可编辑表格与迷你看板卡片 (Kanban & Table Node)**：
  - 允许在画布上直接建立多列泳道轻量 Kanban 卡片，拖拽任务卡；
  - 支持内嵌轻量 GFM 表格编辑卡片，用于多方案对比与数据罗列。

#### 1.2 画布自由手绘与荧光批注图层 (Freehand Ink & Annotation Layer)
- **轻量矢量笔刷**：在画布工具栏增加「画笔 ✏️」与「荧光笔 🖊️」模式（类 Excalidraw 体验）；
- **空间批注与手写草图**：允许在卡片群之间自由手绘箭头、圈选重点、草图手绘；
- **自适应缩放与图层解耦**：手绘轨迹采用紧凑 SVG Path 存储，支持橡皮擦局部擦除，随画布缩放与平移完全等比缩放。

#### 1.3 连线智能绕障寻路算法 (Obstacle Avoidance Routing)
- **痛点**：多卡片高密度排版时，正交折线或曲线容易横穿中间不相关的卡片文字。
- **改进算法**：
  - 正交折线引入轻量 A* / 曼哈顿网格避障算法；
  - 自动将画布上所有节点外扩 16px 视为障碍包围盒（AABB），智能绕行空白间隔，彻底消除线条横穿遮挡卡片。

#### 1.4 白板分镜幻灯片演示模式 (Canvas Presentation Mode)
- **航点相机模式 (Waypoints)**：
  - 用户可为卡片指定演示顺序（1、2、3...）或沿有向连线拓扑顺序自动生成演讲分镜；
- **全屏沉浸飞渡 (Smooth Pan/Zoom Cinematic Transition)**：
  - 按下 `F5` 进入演示全屏，空格键/方向键触发电影级平滑运镜，从一个卡片平滑平移缩放到下一个卡片，无需额外制作 PPT。

### 🧠 Milestone 2：v2.2.0 · 本地第二大脑与全库语义 RAG（2026 Q4 ~ 2027 Q1）
> **定位**：从传统的“关键词字符检索”，进化为“真正读懂你所有思考与知识”的本地端侧 AI 智能体。

#### 2.1 端侧轻量向量嵌入与语义混合检索 (Local Vector Embeddings & Hybrid Search)
- **纯本地 Embedding 引擎**：
  - 利用 ONNX Runtime 或 WebGPU 在本地直接运行轻量级 Embedding 模型（如 `bge-small-zh-v1.5` 或 `all-MiniLM-L6-v2`）；
  - 零数据外传，在断网环境下也能执行语义检索。
- **Dense + Sparse 混合多路召回 (Hybrid Retrieval)**：
  - 将既有的倒排索引（BM25 词频匹配）与语义向量相似度（余弦距离）加权融合；
  - 即使搜索时完全没使用原文档中的专有名词，也能基于概念语义精准匹配召回。

#### 2.2 库内知识全景智能对话助手 (Chat with Your Vault / Local RAG)
- **双模模型驱动支持**：
  - **离线端侧模型**：直连本地 Ollama（DeepSeek-R1、Qwen2.5 等开源模型）；
  - **云端高智模型**：支持用户自带 API Key (BYOK)，直连 Gemini 2.5 Flash / Claude 3.5 Sonnet / OpenAI。
- **可解释性与溯源锚点 (Verifiable Citations)**：
  - 回答的每一个论点，均自动附带对应 Markdown 文件名、小节标题与块引用跳转链接，点击瞬间聚焦高亮源文档，彻底防止 AI 幻觉。

#### 2.3 知识卡片间隔重复记忆系统 (Spaced Repetition / SRS Flashcards)
- **闪卡语法原生解析**：
  - 识别 Markdown 中标记的问答对（`Q: 问题 / A: 答案`）或白板正反面便签；
- **SM-2 / FSRS 记忆曲线算法**：
  - 在每日复盘看板提供“今日待复习”卡片流；
  - 按照“容易 / 良好 / 困难 / 重来”按钮动态调整下次复习周期，打通从“输入记录”到“长期内化”的认知闭环。

#### 2.4 知识体检与双链自动推荐 (Knowledge Health & Auto-Linking)
- **孤岛笔记与碎片合并**：定期扫描内容相似度超过 85% 的碎片记录，提供一键合并建议；
- **智能双链推荐**：在编辑正文时，根据上下文语义，在侧栏静默提示“您曾记录过相关的《XXX》，是否建立双链关联？”。

## ⚙️ 五、 长期技术底座与架构演进原则

在推进所有功能演进的过程中，KnowSpace 研发团队将严格贯彻以下五大底层工程底线：

1. **纯净文件主权原则 (Zero Lock-in & Pure Markdown)**：
   - 所有文档内容以标准 Markdown（GFM）、标准 Frontmatter 元数据或透明的 HTML 注释存储，第三方编辑器（VS Code、Typora、Obsidian）随时可以无损打开，绝不将用户绑架在专有封闭二进制格式中。
2. **极低功耗与恒定 60FPS 帧率标准**：
   - 画布与图谱优先采用增量计算与 RAF 节流；万行长文、千节点网络拓扑下内存占用平稳，杜绝打字粘滞或风扇狂转。
3. **本地物理事务安全底线 (ACID Atomicity)**：
   - 严格沿用临时事务文件（`.tmp`）落盘并 `rename` 的原子性写入机制，杜绝断电或系统崩溃导致空文件；持续监控外部冲突，永远以用户劳动心血的绝对安全为最高优先级。
4. **零网络外泄的隐私第一原则 (Privacy by Design)**：
   - 核心功能（搜索、大纲、图谱、白板、版本快照）100% 本地运算；云端同步必须经由客户端 AES-256-GCM 强加密；AI 功能优先由本地端侧开源模型离线驱动。
5. **严密的全量自动化测试守护 (Zero-Regression Protocol)**：
   - 始终保持 300+ 项自动化单测与组件测试覆盖，任何涉及编辑器核心、AST 映射、文件 I/O、画布连线算法的改动必须通过测试方可合入。
