```mermaid
flowchart TD
    subgraph Space [超立方空间 (HyperSpace Cube)]

        C[Connect · 双链与块级网]

    end

    W <--> CM6
    R <--> AST
    C <--> Graph
    M <--> CM6

    R <--> PDF
```

- **目录上下文展示**：每个文档右侧清晰标注其所属的父级目录路径（如 `docs/architecture/`），即使库中存在多个同名的 `index.md` 或 `README.md` 也绝不混淆。

- **系统支持动作清单**：
  - **主题与视觉**：

    - `开启/关闭打字机垂直居中滚动 (Alt+T)`
    - `开启/关闭专注极简模式 (F10)`

    - `导出高保真矢量 PDF 打印文件 (Ctrl+P)`

  - **文档生命周期**：
    - `新建 Markdown 文档 (Ctrl+N)`
    - `保存当前活动文档 (Ctrl+S)`
- **快捷键实时提示**：每个命令条目右侧带有对应的全局原生物理快捷键徽章（如 `Ctrl+P`、`Alt+T`），让用户在搜索动作的过程中顺便习得快捷键。

## 十四、 工业级数据安全基石与防丢稿守卫

```
用户保存 (Ctrl+S) ──► 写入同目录临时文件 (.tmp) ──► 物理 fsync 刷盘 ──► 原子重命名替换 (Atomic Rename)
```

### 14.1 物理事务原子落盘与断电安全
#### 【案例 14.1】异常掉电与进程崩溃下的零截断损坏保障
- **底层机制**：KnowSpace 绝不在原文件上直接写覆数据，而是先写入同目录隐藏临时文件，调用 OS 级 `fsync` 确保数据真正沉入磁盘物理扇区后，再执行原子重命名覆盖。即便在写入瞬间电脑断电关机，原有文件依然完好无损，绝不留下 0 字节损坏空文件。

### 14.2 UTF-8 BOM 与 CRLF/LF 换行格式保真
#### 【案例 14.2】跨 Windows 与 Linux 团队协作下的 Git 纯净提交
- **底层机制**：打开带 Windows CRLF 或 UTF-8 BOM 的老旧工程文件时，KnowSpace 自动侦测并忠实继承其文件格式。保存时严格保真，绝不在 Git Diff 中产生几千行无意义的换行符全局变动。

### 14.3 外部编辑器并发修改冲突检测与协商
保存前主动比对磁盘物理指纹 `{ size, mtimeMs }`：

![外部冲突协商弹窗](manual-images/18-dialog-conflict.png)

#### 【案例 14.3】VSCode 与 KnowSpace 并发修改同一文档时的安全协商
- **实战流程**：
  1. 在 KnowSpace 编辑的同时，外部 Git 执行了 `git pull` 更新了磁盘上的该文件。
  2. 在 KnowSpace 中按下 `Ctrl+S` 时，系统感知到物理指纹不一致，立即拦截并弹出「检测到文件冲突」对话框。
  3. 提供三种清晰选择：**重新载入磁盘内容**（丢弃本地改动）、**强制覆盖磁盘文件**（以本地为主）、**另存为新文件**（两者兼顾）。用户选择另存为，双方修改安全保全。

### 14.4 全链路未保存守卫拦截
![未保存拦截提醒](manual-images/17-dialog-unsaved.png)

#### 【案例 14.4】误触切章节或关窗时弹出拦截弹窗挽救心血成果
- **实操体验**：只要文档处于 `isDirty` 未保存状态，无论是误触关闭标签、切换目录树章节，还是点击右上角叉号退出，系统都会主动弹出防丢稿弹窗，提供「保存文件 / 放弃更改 / 取消」，彻底消除误操作丢稿遗憾。

- **顶层（多模态卡片层 · HTML DOM）**：
  - **文本卡片 (Text Node)**：双击卡片进入行内编辑，失焦自动渲染为精美 Markdown（支持 LaTeX 公式、代码高亮、Checklist）；

  - **自由拉伸与控制**：卡片右下角拉伸控制手柄，支持尺寸自由拉伸调整。

- **画布逆向萃取为长文 (Canvas-to-Article Transformation)**：
  - 点击顶部「逆向萃取长文」按钮，算法自动依据所有卡片的空间纵向坐标与因果连线拓扑关系进行拓扑排序；
  - 一键将零散白板卡片智能萃取为一篇各级标题完备、引用因果严密的全新 Markdown 专著，并自动保存到当前工程中打开！

### 2. 时间轴面板与 Side-by-Side 双栏 Diff
- **快捷唤出**：通过顶部工具栏 `History` 图标按钮或全局快捷键 `Ctrl + Shift + H` 随时唤出「时间旅行与版本快照历史」弹窗；
- **时间轴列表**：左侧清晰呈现所有历史快照点，精确标记相对时间（“刚刚”、“5分钟前”）、绝对时间戳、行数增减（如 `+18` / `-5`）与快照类型；
- **双栏差异对比 (Side-by-Side Diff)**：
  - 左栏呈现历史快照，右栏呈现当前最新文档；
  - 基于 Myers LCS 算法实现毫秒级行级差异对比（绿色背景代表新增行，红色背景代表删除行）；
  - 行内字符级微粒度高亮，精准定位单个单词或字符的修改；
  - 支持一键切换「双栏对比」与「统一对比 (Unified Diff)」两种视图。

### 3. 一键无损安全还原与手动快照
- **还原至此版本**：点击右上角「还原至此版本」，弹出防误触安全确认，点击确认后立即将工作区当前文档覆盖为历史快照内容，并自动生成一条新的恢复记录；
- **复制快照内容**：支持一键将所选历史版本的全部 Markdown 源码复制到剪贴板；
- **保存手动快照**：支持随时手动打下里程碑检查点标记。

## 十九、 全库毫秒级混合检索引擎与结构化语法 (Hybrid Vault Search)

KnowSpace v2.0.0 检索引擎全新升级，彻底告别单文件线性暴力扫描，引入文档级与段落块级的高性能倒排索引（Inverted Index），实现键盘键入即刻（< 15ms）出结果。

### 1. 结构化检索语法体系
不仅支持常规全文关键词，更原生支持面向高阶知识管理工作流的结构化检索语法：
- **标签筛选**：
  - `tag:#架构` 或 `tag:架构` 或 `#架构`：秒级筛选包含 `#架构` 标签的所有段落与文档；
- **双链筛选**：
  - `link:[[分布式协议]]` 或 `link:分布式协议`：秒级检索所有引用或反向链接到该目标文档的段落；
- **严格短语检索**：
  - `"raft consensus"`：用双引号包裹词语，执行严格连续字词精确匹配；
- **排除词过滤**：
  - `-keyword`（如 `raft -paxos -废弃`）：排除包含指定负向词语的搜索结果；
- **日期范围过滤**：
  - `after:2026-09-01` / `before:2026-09-08`：按时间范围进行精准圈选。

### 2. 双范围检索模式与语法快捷辅助
- **搜索范围切换**：
  - 搜索面板顶部常驻 `[当前章节]` 与 `[全库检索]` 切换标签；
  - 在全库检索模式下，搜索结果卡片直接呈现所属章节徽章（如 `[架构总览]`）、大纲层级与精准物理行号标签（如 `L12-15`）；
- **快捷语法辅助芯片 (Syntax Chips)**：
  - 搜索框下方配备 `tag:#`、`link:[[`、`"短语"`、`-排除` 快速插入辅助芯片，单击即可就地插入对应语法模板；
- **跨文档平滑导航与微光脉冲**：
  - 点击全库搜索结果中属于其他章节的卡片，系统自动秒级切换至目标章节，平滑滚动至对应物理行，并激活 1.8 秒电光蓝柔和高亮微光脉冲！
