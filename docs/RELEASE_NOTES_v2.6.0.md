## ✨ 一、思维导图：导出与导入闭环

### 🧠 新增 `.xmind`（ZIP + DEFLATE，自己写）

不依赖第三方库：DEFLATE 解压与 ZIP 读写为自写实现，因此 **`.xmind` 是当前唯一一种本应用能导出、也能读回来的格式** —— 导出与导入之间可以往返验证，其余格式只能靠人眼。

- **导出 7 种**：PNG（2× 视网膜透明底）/ **SVG** / **打印即 PDF** / OPML 2.0 / FreeMind `.mm` / **`.xmind`** / Markdown 大纲
- **导入 3 种**：`.opml` / `.mm` / `.xmind`，均**导入为新文档**，并把文件里携带的**备注、链接、标签、标记、关系线、概要、边界**一并写进该文档的伴生文件
- **多画布的 `.xmind`**：只导入第一张画布，并在提示里**说明还有几张没进来** —— "已导入"不加这一句就是半个真话
- **不写进导出的东西**：浮动主题（它们在文档之外）；边界颜色与关系线形态也不映射进 `.xmind` 的样式记录 —— 映射得出来，但**没法验证**，写了等于把一个没验过的猜测固定进文件

## 🃏 二、闪卡：从"能复习"到"日常可用"

> 记下来的知识会随时间遗忘。这一版让"每天真的会去复习"这件事成立。

### 📂 四种卡片来源，并记住上次用过的

| 来源 | 读什么 | 说明 |
| :--- | :--- | :--- |
| **闪念 Space** | `Space/` 目录下的闪念 | 默认 |
| **当前知识库** | 已打开工作区的全部章节 | 第一次切过去时才读 |
| **自定义文件夹** | 你挑的文件夹，**最多 5 个** | **只是复习，不会把它们打开成工作区**；记住的是**路径**，下次重新列一遍，所以新写的卡进得来 |
| **当前文档** | 正在编辑的那一篇 | **有未保存改动时不可选**并说明原因 |

面板**记住上次用过的来源**；记住的那个这次用不了时（知识库没开、文件夹已取消、文档未保存）自动退回 Space。

### ↩️ 评分可撤销一步

`重来` 与 `良好` 只隔一个键位，按错的那次会**静默地**改动一张卡的调度。现在点标题栏的撤销按钮或按 `Ctrl/Cmd + Z` 即可（在输入框里仍是编辑器自己的撤销）：

- 写回**评分前**的调度；
- 从没复习过的卡片，**把那一行整个收回** —— 一篇只评过一次就被撤销的笔记，与**从未评过时逐字节相同**；
- 那张卡**回到本轮**（调度被收回了，就等于没有复习过）。

### ⌨️ 两个新入口

- **命令面板**（`Ctrl+K`）→「**开始复习：闪卡**」，一步直达；
- **斜杠命令** `/闪卡` → 三条模板（问答 / 一行一问一答 / 挖空），**插进去就已经是一张合法的卡片**，光标停在示例文字上。

### 🛡️ 写回是合并，不是覆盖

评分写回前会**重新读一次文件**，只把自己那一行合并进**文件当下的内容**：

- 复习期间在别处（编辑器、同步盘、闪念胶囊）对同一文件的改动**不会被覆盖**；
- 复习期间被删掉的卡片，它的进度行**被丢弃**，而不是写给一个不存在的卡片；
- 文件读不到时**明确报错并留在原地**，不拿手里的旧副本硬写。

## 🛡️ 三、修复：三处会静默写坏笔记的缺陷

这三处都不是崩溃，而是**不报错、界面正常、数据悄悄变错** —— 因此都补上了"先失败、后修复"的测试作为证据。

1. **知识库来源把进度写进别的文档**：批量读取会丢掉读不了的项（以及**任何不是 Markdown 的章节**，例如 `.canvas`），而来源按**位置**把结果与路径对齐 —— 只要知识库里有一个画布文件，它之后每一章拿到的都是下一章的正文，评分于是写进**别的文档**。现在**按路径配对**，并有测试钉住（修复前：卡片来自 `c2.md`，实际写盘的是 `c1.md`）。
2. **同一张卡出现在两篇笔记时被算成两张**：卡片身份由内容派生，所以那是**一张卡**，而队列与统计各算两份 —— 头部说"2 张待复习"，评完一张却是"本轮复习 1 张"，进度条永远到头不了。
3. **撤销唯一一次评分会留下空行**：删除元数据块时留下了它前面那个空行 —— 而"撤销"的语义是**恢复原样**。
