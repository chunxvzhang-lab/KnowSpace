## 🔗 闪念双向同步：正文与时间线两处状态实时一致

- **阅读视图点击待办复选框 → 直接回写落盘**：此前阅读页的复选框只是切 DOM 状态，刷新即复原。现在按「块起始行 + 块内序号」精确定位源码行（块虚拟化下 DOM 全局序号必然错位，行号锚不随虚拟化变化），翻转后走与 Ctrl+S 完全相同的保存路径；CRLF 文档不会因一次点击被整体改写换行符，`[[...]]` 内联引用里**别的文档**的任务行也不会被误翻。
- **编辑器改动保存后 → 时间线即时刷新**：勾选 / 取消勾选 / 编辑 / 删除待办行，凡保存落盘（手动 Ctrl+S 或自动保存），主进程失效闪念摘要缓存并广播，时间线卡片随之更新——此前目录 mtime 不变会导致时间线一直读到旧缓存。
- **时间线勾选 → 正文预览重读**：在时间线勾选任一待办，打开着的这篇闪念正文立即同步。两处安全策略对称：文档有未保存改动时，正文侧不抢跑保存、对端刷新也让路——任何一侧进行中的编辑都不会被另一方顺带提交或覆盖；落盘那一刻两处必然一致。
- **误伤防护**：`[[...]]` 内联引用里别的文档的任务行不参与本文件的回写；块虚拟化窗口外的任务行靠行号锚精确定位，不依赖 DOM 全局序号。

## 🖱️ 资源管理器右键「新建」三种 KnowSpace 文件

- 在任意文件夹右键 → 新建，直接创建 **KnowSpace Markdown 文档**、**空间白板**（`.canvas`）与**思维导图**（`.mindmap`，Markdown 大纲，双击进导图视图）；模板内容与应用内「新建」逐字节一致。
- 在「关于 → 系统运行与系统集成偏好」中逐项开关；写入**用户级注册表**，无需管理员权限；`.md` 只追加进「打开方式」候选，**不改变既有的默认打开方式**；`.canvas` / `.mindmap` 为私有扩展名，设为默认用 KnowSpace 打开；取消勾选即从系统还原（`.md` 的默认类型名恢复为启用前的注册者）。

## 🗂️ 闪念时间线交互

- **双击卡片在阅览页打开详情**，时间线保持原位，浏览节奏不被打断（打开 Space 文件不再把侧栏拽回大纲页）。
- **「常驻模板」页处于前台时，点击窗口外部不再消失**（失焦保持），切回速记页即恢复默认行为。

## ⚙️ 工程与文档

- 「关于」的版本更新日志精简为**只保留最新版本一节**（历史条目移除），守卫测试改为断言"恰好一节、且以当前版本号开头"，发布时替换本节内容即可。
- 一键发布编排（`npm run release`）承接本版发布：六处版本一致性门禁、两轮全部门禁、产物校验（MSI 签名、压缩包一致性、包内版本握手）、GitHub 发布与独立核验、网络抖动重试推送。
