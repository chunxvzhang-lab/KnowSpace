## 一、项目目标与核心价值

### 1.1 一句话定位

**KnowSpace** 是一款**本地优先（Local-First）、零格式锁定、空间化拓扑认知**的现代化个人知识工作台。

### 1.2 产品理念

> **Write. Read. Connect. Know.**（记录 · 阅读 · 连接 · 认知）

以「超立方空间 HyperSpace Cube」为设计核心，为用户提供一个收纳所有想法、文档、图表与知识的**私密安全空间**。

### 1.3 核心价值主张

| 价值维度 | 具体承诺 | 落地体现 |
| :--- | :--- | :--- |
| **数据主权** | 笔记永远是纯文本，随时可被第三方工具读取 | 标准 GFM Markdown + Frontmatter；白板用标准 JSON Canvas 1.0 |
| **隐私安全** | 未经授权绝不外发任何数据 | 全本地运行；无遥测；快照存于库内 `.knowspace/snapshots/` |
| **性能体验** | 大规模知识库也要"秒开不卡" | 协作式空闲分片索引；32MB LRU 缓存；120FPS 白板引擎 |
| **认知升维** | 从"线性记录"到"网状 + 空间"思考 | 双链 / 知识图谱 / 无限白板 / 思维导图无损同步 |
| **可持续性** | 功能增长不牺牲文件纯净度 | 样式以标准 Markdown 注释持久化，Git 中零侵入 |

### 1.4 目标用户

开发者、写作者、研究者等**长期积累型知识工作者**——尤其是重视文件可迁移性、拒绝云锁定的人群。

### 5.3 不可妥协的工程红线（📘 规划，建议纳入评审清单）

2. **物理事务原子落盘** —— `.tmp` 写入 → `fsync` → `rename`，杜绝断电损坏
3. **零回归测试协议** —— 核心改动必须同步补齐单测
4. **恒定高刷与冷冻机制** —— 非激活标签冷冻，单标签增量内存 < 5MB，长文打字延迟 < 16ms
5. **绝对零隐私外泄** —— 无授权不遥测；同步未加密不出网；AI 优先端侧
