# KnowSpace v2.6.1

**交互对象收口：顶栏、按键归属、链接徽章与节点类型。**

这是一个补丁版。v2.6.0 之后使用导图时暴露出来的问题，以及三处会让读者"看到的和发生的不一致"的交互缺陷。**没有改变任何既有文件格式**：`.md`、`.canvas`、伴生文件与 `.xmind` 都与 v2.6.0 完全一致，升级不需要迁移。

---

## 🛠 修复

### 打开文件目录与大纲后，顶栏右侧的控件消失

顶栏原本是**定高 44px 且不换行**，中间那排在装不下时改为**横向滚动**并把滚动条藏起来 —— 于是导图区一变窄，右侧的缩放、导出等控件就被推出可视区：既看不见，也没有滚动条可拖，滚轮还被画布的缩放接管。**现在装不下就换行**，顶栏自己长高，什么都不会被推到框外；滚轮落在顶栏上不再缩放画布。

### 读者在输入框里打字，导图在背后自己动

导图的快捷键挂在窗口上，而保护只问了一句"是不是正在编辑节点文字"。插入符停在面板自己的输入框里时它答不上来，于是：

- 在**备注框**里按 `Delete` —— 被删掉的是这条备注所属的**整个主题**（连同它的子主题）
- 在**标签 / 链接框**里按 `Ctrl+V` —— 贴进来的是**一整个分支**（多出一个主题卡片）

**现在：有插入符的地方，键属于那个框**（输入框、文本域、下拉、可编辑区）；`Escape` 是唯一的例外，因为它不改变任何内容。同时节点菜单里补上了此前只存在于快捷键说明里的三行 —— **复制整个主题 / 剪切整个主题 / 粘贴为子主题** —— 删除行也明确写着「**删除整个主题及其子主题**」，读者不必再从行名的字数去猜它作用于什么。

### 三处静默缺陷（v2.6.0 发布后确认）

- **知识库来源按路径配对**：此前按位置配对，会把复习进度**写进另一篇文档**；现在按路径配对，同一张卡出现在两篇笔记里也**只计一次**（按首次出现的笔记归属）。
- **撤销唯一一次评分**会留下空行：现在会把那一行整个收回，**一篇只评过一次就被撤销的笔记与从未评过时逐字节相同**。
- **闪卡读取知识库卡死**：分片解析后，7300 ms → **2357 ms**（大库不再冻结窗口）。

## ✨ 改进

### 节点上的链接徽章可以直接点击打开

它标的是一个去处，所以它现在是一条路：**外链走系统浏览器**，`[[笔记]]` 与 `#标题` 走阅读器自己的两条通道。命中区从一个 9px 的点放大成看不见的圆，悬停提亮，提示里写出目标；**按下时会吞掉事件** —— 同一个盒子上还挂着"选中"和"拖拽排序"，去一个链接不该顺手把主题挪走。自由主题上的徽章同样可点；**导出的 SVG 里仍然是原来的记号**。

### 节点图标重做为「节点类型」

原来是 34 枚按"重点 / 状态 / 时间与目标 / 人物与来源 / 资料"分组的图片：同一个情形，两个读者不会选同一枚，于是它只是装饰。现在是**一行 8 枚、一名一义**：

| 待办 | 进行中 | 已完成 | 疑问 | 想法 | 风险 | 重点 | 参考 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |

每枚带一句"什么时候戴它"；**一个主题至多一枚**，点击设置、再点同一枚取消；菜单上写出当前类型名。真正的用处是**搜索**：在画布搜索里输入类型名（如「待办」），**所有标了它的主题会被找出来** —— 这是这个功能此前没有的用途。旧文件里写过的图标 id **仍然会画出来、也仍然能清除**，升级不会静默丢标记。

### 其它

- **点击顶栏收起右键菜单**，且不像点击画布那样连选择一起丢掉。
- 「换到另一侧」弹层的两行字改为**正文色 + 加粗按钮**，不再需要凑近看。
- 顶栏里**缩放与导出归到右侧同一组**：在看什么、要带走什么，不该跟着中间那排地图级控件重排。
