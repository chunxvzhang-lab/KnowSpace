# KnowSpace v2.7.3

**上下标与行内高亮渲染；右键格式工具栏扩展。**

v2.7.2 之后的补丁版：右键格式工具栏新增上标 / 下标，并补齐 `==高亮==` 的渲染实现。
**没有改变任何既有文件格式**：`.md`、`.canvas`、`.mindmap.md`、伴生文件与 `.xmind`
与 v2.7.2 完全一致，升级不需要迁移。

## ✏️ 右键工具栏新增上标 / 下标

编辑器右键菜单的格式工具栏（加粗、斜体那一排）新增两个按钮：

- **上标（x² 图标）**：选中文本包裹为 `^文本^`，预览渲染为真上标——
  `E = mc^2^` 显示为 E = mc²；
- **下标（x₂ 图标）**：包裹为 `~文本~`——`H~2~O` 显示为 H₂O。

这是 Pandoc / Obsidian 通用的行内记号，所以从其他笔记软件粘贴的内容也能正确显示。
两个按钮都是**开关式**：对已带标记的选区再点一次即剥掉标记恢复原文。

## 🖍 补齐 `==高亮==` 渲染

格式工具栏的「文本高亮」按钮从上线第一天起就插入 `==文本==` 记号，但渲染管线里
从来没有对应的规则——预览里显示的是字面文本（与脚注当时一模一样的情况：按钮在、
管线缺）。这一版补上实现，`==重点==` 现在以主题化高亮底色显示（浅色 / 深色 / 墨水屏
三主题各有配色）。

## 🛡 与既有语法的冲突防护（负向测试钉住）

行内记号扩展最容易误伤相邻语法，以下每一项都有专门的负向测试：

- `~~删除线~~` 仍走内置删除线规则，单波浪线不会吞掉它；
- 未解析的脚注 `[^1^]` 保持原样（`^` 紧跟 `[` 的形状不按上标解析）；
- 段落尾部的块引用锚 ` ^block-id`（无闭合符）照常工作；
- 带空格填充（`a == b`）或未闭合的输入保持字面；
- `===` 连等号输入不会被吃进高亮。
