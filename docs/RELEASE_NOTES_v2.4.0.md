# KnowSpace v2.4.0

> **发布日期**：2026-09-17
> **上一版本**：v2.3.0
> **完整变更**：`git log v2.3.0..v2.4.0`

这一版聚焦三件事：**让白板的排布真正可调**、**让多模态媒体的插入顺手**、**让导出与显示完全一致**。同时修掉了一批长期存在的稳定性问题。

---

## ✨ 本次亮点

### 1. 排布间距可以「随手调」了

以前把卡片排成环形或网格后，间距是固定的，想调整只能重新排一次。现在：

| 排布 | 调距方式 |
| :--- | :--- |
| **环形 (Ring)** | 对齐菜单里的**半径滑块**，或**直接拖动环上任意卡片** |
| **网格 (Grid)** | **拖动任意卡片**实时改变行列间距 |

- 拖动时其余卡片**围绕被拖动卡片实时重排**，所见即所得
- **整段手势只记一条撤销**，不会把历史栈刷爆
- 环半径有**防重叠下限**（基于卡片对角线自动计算），拖到底也不会塌成一堆

**新增**：多选后拖动**选中组中间的空白区域**可整体平移，间距保持不变；同时**不会误拖画布背景**。

### 2. 多模态媒体插入

- **右键菜单一键插入**图片 / 视频 / 音频 —— 文件对话框已按类型预过滤
- 卡片**落在你右键点击的位置**，而不是视口中心
- **双击媒体卡片全屏预览**：图片可缩放平移、视频自动播放、音频显示播放器；`✕` 或 `Esc` 关闭
- **修复图片卡片显示为破图**：媒体路径原本被当作相对 HTML 页面解析，现在正确按画布文件目录解析

### 3. 导出与剪贴板彻底修复

这一版花了最多力气在导出链路上，因为此前「导出 PNG 得到 SVG」「复制到剪贴板无反应」都指向同一个根因：**渲染进程的 canvas 栅格化被浏览器安全策略否决**。

现在：

```
① 渲染进程快速栅格化
   ↓ 失败
② 主进程离屏 capturePage() 渲染 —— 仍然出 PNG ✅
   ↓ 失败
③ 才降级为 SVG，并如实告知（不再假装成功）
```

- **离屏渲染**由 Chromium 自己合成页面，**不受 canvas 污染规则限制**
- **剪贴板改走系统原生 API**（`clipboard.writeImage`）—— `navigator.clipboard` 需要窗口聚焦与用户手势，在 Electron 中很容易失效
- **导出配色与屏幕主题 1:1 一致**（浅色 / 墨屏 / 暗黑），此前浅色导出会偏灰、墨屏会丢失纸色
- 导出 SVG 前做 **XML 合法化**（修复未自闭合标签与无值布尔属性），保存的 `.svg` 可在浏览器 / Illustrator 正常打开
- 大画布有**尺寸钳制**（单边 ≤16384px、总量 ≤24MP），不会因内存峰值崩溃

### 4. 12 色专业调色板

调色盘从 6 色扩展到 **12 色**（键 1–6 仍为 JSON Canvas 标准色，保证与其他工具互通；7–12 为扩展色）。批量改色面板新增**自定义 HEX 取色器**：

- 拖动色盘**实时预览**，停手后提交**一条**历史
- 修掉了此前**拖动取色时闪退**的问题

### 5. 连线不再遮挡文字

连线图层下沉到卡片之下 —— 即使几何路径经过卡片，也会被卡片自然遮挡。搭配**多障碍链式绕行**（一串相邻卡片一次绕开，而非只绕第一个），白板阅读体验显著提升。

### 6. 侧边栏自适应

修复了**全屏 / 矮窗口下底部按钮消失**的问题：侧边栏改为可滚动，并按窗口高度三级收紧（隐藏 Logo、缩小按钮）。Tooltip 改用 portal 渲染，不被滚动容器裁切。
