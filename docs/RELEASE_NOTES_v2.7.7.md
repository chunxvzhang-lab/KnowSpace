# KnowSpace v2.7.7

**界面可读性全面收口；性能基线装上防污染闸门。**

v2.7.6 之后的质量修复版：把三轮审计里挖出的**真实可见性问题**一次修完——墨屏主题下命令面板白字压白底（完全看不见）的真 bug、23 处一直没生效的图标着色、闪念胶囊控件在三个主题下都不达标的淡描边；同时给性能基线加了自动化守卫，脏窗口从此无法无声改写基线。**既有文件格式一律不变**（`.md`、`.canvas`、`.mindmap.md`、伴生文件与 `.xmind` 与 v2.7.6 完全一致，升级不需要迁移）。

## 🎨 对比度与样式正确性

- **墨屏主题命令面板修复（真 bug）**：eink 主题下面板是白底，而条目标题与搜索框文字读的是一个从未定义令牌的浅色兜底值 ⇒ **白字压白底 1.00:1，输入与全部条目完全不可见**。改读既有 `--text` 令牌后实测 17.40:1。同类"幽灵令牌"共 16 处全部收口到既有词汇。
- **图标着色类名真正生效**：`.text-orange` / `.text-cyan` 在 23 个元素上裸用，而全仓只有要求父类的复合规则——这些图标一直显示成继承色，写代码的人以为它是橙/青。新增按主题取值的工具类（浅色/墨屏自动压暗同色相），实测最差面 ≥3.5:1；并新增守卫防止这类"空转类名"再出现。
- **闪念胶囊控件描边全部达标**：按钮与标签的半透明淡描边经逐主题实算**三个主题全低于 WCAG 非文字 UI 的 3:1**（最差 1.19:1，此前技术债表误记为"仅浅色有问题"）。描边统一换实色令牌（墨屏取压深一档的同色系），修复后最差面 3.61:1；守卫同步纳入 hover 态判据（盲区正是"只查基础态"造成的）。
- **关系图旧弹窗死样式清理**：上一代全屏关系图弹窗退役后遗留 61 条规则 / 28 个永不匹配的选择器（graph.css 890 → 467 行）。删除前后对代码中真实可渲染的 148 个候选元素逐一比对实际生效声明——零差异，外观不变有直接证明而非"守卫放行"。

## 🛡️ 工程地基

- **性能基线防污染闸门**：基线捕获原先无条件写盘——机器繁忙时的一次测量会把更差的数字"成功地"提交进基线，即无声放宽棘轮（历史上靠人肉看数字扔过两次）。现在双判据把关：同一指标采样散度超限拒绝、比已提交基线差出容差也拒绝，脏窗口直接不写盘；容忍度沿用回归检查的一贯口径。
- **发版一致性门禁补最后一道口子**：README 版本徽章此前不在任何门禁内（发版脚本的白名单缺它、能改它的脚本无人调用），v2.7.6 就带着 v2.7.5 的徽章出过一次门。现在静态测试 + 发版前置检查双向钉住三处标记互一致且等于 package.json。
- **版本提升脚本不再把文档写成 CRLF**；App.tsx 摘掉 lint 豁免名单（实测 0 hook，强开规则干净）。
