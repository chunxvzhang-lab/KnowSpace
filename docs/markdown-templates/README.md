# Markdown 文档模板使用指南

这套模板按日常文档工作的顺序整理：先记录，再安排工作、沟通协作、形成方案，最后验收、复盘和归档。共 20 个模板，按需复制，不必每次填满所有章节。

## 从软件内置入口新建

在 KnowSpace 桌面版首页、顶部工具栏或左侧活动栏点击“从模板新建”，也可在 `Ctrl+K` 命令面板中搜索这个命令。模板窗口提供分类、名称搜索和内容预览；选好后点击“使用模板新建”，在系统保存窗口修改文件名与位置，保存后进入实时预览编辑。

当前文档存在未保存修改时，会先询问是否保存。取消模板选择或保存窗口不会创建新笔记。内置模板不会因创建或填写笔记而被改动。

## 复制与填写

1. 找到适合的 `.md` 文件，复制到自己的知识库或项目目录，保留原模板供下次使用。
2. 重命名文件，并把第一行标题改成实际主题。
3. 替换 `【待填写】`、`YYYY-MM-DD`、`HH:mm` 等人工填写提示；本模板包没有自动替换日期或变量的功能。
4. 删除不适用的章节和示例行。没有结论时写“待确认”，不把空白误当成已完成。
5. 行动项尽量写清楚“谁、做什么、何时完成、用什么确认完成”；确认完成后再把 `- [ ]` 改成 `- [x]`。
6. 在 KnowSpace 中打开副本，用实时预览填写，用阅读视图检查完整呈现。表格在编辑时保留 Markdown，切到阅读视图查看排版。

也可继续直接复制文件使用。内置入口和文件模板均需手动填写日期与占位内容。模板中的待办仅为填写示例，新建后改成实际任务；如不希望原模板出现在知识库的待办收集中，可把文件模板包保留在知识库外。

## 命名与目录建议

只在需要按时间排列的文档前加日期；长期维护的知识和手册使用主题名。采用 `YYYY-MM-DD` 可按文件名自然排序。下面的目录仅作参考，按自己的工作量裁剪即可。

```text
工作知识库/
  00-收件箱/
    YYYY-MM-DD-临时想法.md
  01-工作记录/
    YYYY-MM-DD-工作日志.md
    YYYY-MM-DD-周计划与周报.md
  02-项目/
    项目名称/
      项目导航.md
      项目计划.md
      YYYY-MM-DD-会议纪要.md
      方案设计.md
      验收记录.md
  03-知识与手册/
    主题名称-知识笔记.md
    流程名称-操作手册.md
  90-归档/
```

## 让文档真正参与工作

- **每天结束前**：清理快速记录，把内容转成任务、项目资料或知识笔记；在工作日志里补上结果。
- **每周回顾时**：从日志中挑出成果、延期和需要支持的事项，形成周报；未完成事项重新决定是否继续。
- **会议结束后**：确认决议和行动项，给每项安排负责人和截止日期；未决问题明确下一次确认时间。
- **项目推进时**：项目计划维护范围和里程碑，项目周报只写变化；决策发生后同步到方案，避免多处内容冲突。
- **交付结束后**：保留验收证据和复盘结论，把能复用的经验提炼成知识笔记或 SOP，再归档过程资料。

## 链接、来源与版本

- 同目录文档可写 `[方案设计](方案设计.md)`，父目录可写 `[项目导航](../项目导航.md)`。文件改名或移动后检查链接。
- 需要 KnowSpace 双链时，填写真实文档名，例如 `[[实际文档名]]`；模板未预填占位双链，减少无效关系。
- 引用材料写清标题、作者或机构、发布日期、定位页码或章节、访问日期和实际链接；区分引用事实与自己的判断。
- 长期维护的文档更新“更新时间”；重要范围或结论变更记一行变更说明。模板中没有自动版本管理。
- 使用标准标题、列表、任务框、引用和表格。为避免被识别为复习卡，模板未使用高亮挖空和问答卡片语法。

## 一条完整的使用路径

临时收到需求时，先用 **快速记录** 收下；确认要做后写 **需求说明** 和 **项目立项与计划**；讨论时用 **会议纪要**；需要比较路径时用 **对比选型与决策**；执行时维护 **项目进展周报**；交付时用 **验收清单与记录**；结束后写 **项目复盘**，将长期有用的内容整理进 **知识笔记** 和 **操作手册 SOP**。
