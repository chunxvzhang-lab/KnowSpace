# KnowSpace v2.6.3

**导图顶栏重排：双栏展开时，两行对齐成一列。**

这是一个补丁版。v2.6.2 之后，在「文件目录 + 大纲同时展开」时顶栏暴露出来的排版问题。**没有改变任何既有文件格式**：`.md`、`.canvas`、伴生文件与 `.xmind` 都与 v2.6.2 完全一致，升级不需要迁移。

---

## 🛠 修复

### 双栏展开时，顶栏看起来是斜的

问题不在留白，而在**换行由谁决定**。顶栏原本是一条**会自己换行的横排**，而中间控制区的 flex 基准宽度是它的**最大内容宽度** —— 等于先把整行占下；于是被挤到第二行的是右侧那一组（缩放 + 导出），它独自靠右、**上方空着半行**，而标题又在两行之间垂直居中。文件目录与大纲一开，顶栏大部分时间就是这个状态。

现在顶栏是一张**网格**：标题一列、控件区一列、看什么 / 带走什么（缩放 + 导出）一列。控件区再分成结构控件与设置控件两块 —— 装不下时，设置那块**整排**落到第二行，并从**控件列的左边缘**起排、可一直伸展到右端：前者让两行读成一列，后者让它不必再挤第三行。缩放与导出留在**第一行右上**，不参与重排。

### 窄档位下顶栏上下贴边

各窄档位此前只调左右内边距，把上下写成了 0 —— 一行的时候够用，两行就贴边。现在统一补回。

### 主题与布局两个下拉看着像被禁用

它们没有边框、还比旁边的按钮矮一截，文字用的又是 `--text-primary`（在没有定义它的主题里会落回一个偏暗的值）。现在整组做成一个控件：边框、按钮同高、正文色。

## ✨ 改进

- **一行还是两行，由导图区自己的宽度决定**：用的是容器查询 —— 查询的是导图实际拿到的那块地方；打开的侧栏会改变它，窗口宽度不会。导图区宽过 1800px（各块实测宽度之和）时，设置那块回到第一行，顶栏恢复成一行。
- **控件尺寸与间距统一**：控件一律 30px 高（搜索框与缩放读数此前矮一截，看着是"漂"在中间的）；组与组之间 6px、组内 4px —— 间距的分级就是层级的分级。
- 两行版里，结构控件那一行不再以分隔线收尾：它后面不是另一个组，而是换行。
