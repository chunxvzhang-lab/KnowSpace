# KnowSpace v2.7.1

**思维导图下拉菜单修复；长文档打字不再卡顿；标签切换快约 10 倍。**

这是紧随 v2.7.0（架构减负版）的补丁版：修复 v2.7.0 引入的一个显示缺陷，并把 v2.7.0
铺好的架构地基第一次兑换成用户可感的性能。**没有改变任何既有文件格式**：`.md`、
`.canvas`、`.mindmap.md`、伴生文件与 `.xmind` 与 v2.7.0 完全一致，升级不需要迁移。

---

## 🎨 修复：思维导图下拉菜单在浅色主题下不可读

v2.7.0 的思维导图工具栏把主题/布局选择器从手写菜单换成了原生 `<select>`（为了白拿
它的键盘与无障碍处理），但弹出列表是**操作系统画的**，不随应用主题重绘——Windows
的 Chromium/Edge 对列表项的样式化是黑盒：无论样式表写什么，深色弹层上的菜单文字
实测对比只有 1.22:1，几乎不可见。两轮 CSS 修复（恒定深色对、主题跟随变量对）都无法
触及它，重打包也无效——问题从来不在样式表里。

现在这两个下拉改为**手写弹层**（portal 到文档顶层、跟随应用主题的令牌配色、完整键盘
支持：↑↓ 循环、Home/End、Enter/Space 提交、Esc 关闭、点击外部收起；combobox/listbox
无障碍语义由测试钉住）。配对的底色与字色由守卫逐主题验算对比度——历史失效形状
作为负向样例留在测试里，谁改回去立刻变红。

## ⚡ 长文档性能：架构地基的第一次兑现

v2.7.0 拆出的块级渲染管线，这一版开始按块工作：

| 场景（10 万字文档实测） | v2.7.0 | v2.7.1 |
| --- | ---: | ---: |
| 打字停顿后的最长主线程任务 | 169 ms | **0 条 >50ms 长任务** |
| 文章 DOM 节点数 | 6,842 | **191** |
| 标签切换最长任务 | 572 ms | **58 ms**（约 10 倍） |

原理：一次击键只弄脏约 2,300 个内容块中的一块——现在只有那一块重新净化并替换
（其余块的原地 DOM 节点保持不动，连选区高亮都不受打扰）；文章只渲染视口附近的
块，窗外以保留行号锚点的占位段聚合（滚动同步的行号映射因此原样成立）。逐主题的
文字/底色对比度由守卫按 styles.css 的实际值验算。
