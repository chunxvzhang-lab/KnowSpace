# scripts/_archive · 一次性脚本归档区

这个目录存放**已经完成使命的一次性迁移脚本**。它们的共同特征：

- 名字以 `extract-` / `append-` / `replace-` / `remove-` / `split-` 开头，对应某次
  具体的代码搬迁或清理动作；
- **只被运行过一次**，产物已经合入主干并随版本发布；
- 现在没有任何脚本、npm script 或构建流程引用它们（归档前已逐一核实）。

## 保留理由

git 历史同样保存了这些脚本，但「当时为什么那样拆」散在几百个 commit 里。
这批脚本本身就是拆分方案的文字记录（比如 `extract-mindmap-layout.cjs` 的内部
就是导图布局域的边界清单），在做同类拆分时是最直接的参照。

## 何时可删

满足以下任一条件即可整目录删除：

1. 对应的拆分/清理工作已有**成文的边界记录**（如 `docs/` 中的模块划分表），
   脚本不再承担「记录历史」的职责；
2. 拆分后的模块再次被重构，脚本的边界描述已经失真。

## 约定

- **不要再次运行这里的任何脚本**——它们的产物已在主干，重跑等于二次改动；
- 新的一次性脚本从写下的第一天起就放进本目录（或在完成使命后立刻移入），
  并在文件头注释里写清「它做了什么、产物在哪、何时可删」；
- 长期使用的工具脚本（打包、发版、基线、守卫）**不属于这里**，留在 `scripts/` 根目录。
