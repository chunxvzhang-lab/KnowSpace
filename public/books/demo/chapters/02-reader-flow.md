# 阅读流程

本章聚焦核心阅读路径。

## 打开并定位

左侧栏显示章节。第二个侧栏可以显示当前文档大纲、书签或搜索结果。

## 保存书签

点击工具栏里的书签按钮，或按 `Ctrl + B`。一个书签会保存：

| 字段     | 用途                   |
| -------- | ---------------------- |
| 章节     | 跳转前先打开正确文件   |
| 标题     | 优先定位稳定的语义锚点 |
| 滚动比例 | 标题移动后的兜底位置   |
| 摘录     | 作为可读标签和漂移提示 |
| 校验值   | 检测章节内容是否变化   |

## 跳回书签

打开书签标签页并点击任意保存项。应用会在需要时切换章节，然后恢复保存的标题或兜底滚动位置。

## 在章节内查找

第一版搜索刻意限定在当前章节内。这样对内置书籍来说更快，也更容易理解。

试着搜索 `书签`、`章节` 或 `兜底`。
